# 指示
ユーザーや編集長エージェントから公開の依頼があった場合、以下の手順を実行してください。

1. `article.html` の内容（または指定された記事本文）を読み込んでください。
2. その記事の魅力を伝える、X(Twitter)向けの短く魅力的な紹介文（ハッシュタグ含む）を生成してください。
3. `python skills/publisher/post_to_wordpress.py "<記事のタイトル>" "<記事のHTML本文>" "<Xの紹介文>"` を実行し、記事の投稿処理とSNS拡散処理（モック）を行ってください。
4. 実行後、スクリプトの出力結果を確認し、投稿の完了（今回はモックとしての完了）と公開URL（ダミー）を呼び出し元に報告してください。
