# 指示
ユーザーや編集長エージェントから執筆の依頼があった場合、以下の手順を実行してください。

1. 指定されたトピック（または `topics.txt` の内容）を受け取ります。
2. 執筆に必要な追加情報を得るため、`python skills/writer/scrape_info.py "<トピック名>"` を実行し、モックの追加情報データを取得してください。
3. 取得した情報と自身のAIモデル（Gemini）の推論能力を組み合わせて、以下の構成で記事のHTMLを作成してください。
   - キャッチーでSEOを意識したタイトル（`<title>`タグまたは`<h1>`タグ）
   - 導入文
   - 見出し（`<h2>`, `<h3>`）を用いた整理された本文
   - まとめ
4. 生成したHTML記事を `article.html` として保存してください。
5. 執筆完了と記事の概要を呼び出し元に報告してください。
