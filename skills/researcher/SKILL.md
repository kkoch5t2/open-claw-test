# 指示
ユーザーや編集長エージェントからリサーチの依頼があった場合、以下の手順を実行してください。

1. `python skills/researcher/fetch_trends.py` を実行して、今日のサッカートレンドデータを取得してください。
2. 取得したデータ（標準出力）を解析し、最もバズっている話題や検索ボリュームが伸びそうな移籍情報を1つ〜3つピックアップしてください。
3. ピックアップした内容を整理し、「今日の記事ネタ」として `topics.txt` に保存してください（ファイルがなければ作成してください）。
4. 保存したトピックの概要を呼び出し元に報告してください。
